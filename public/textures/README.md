# textures

Процедурные SVG-текстуры картотеки native/.

| Файл | Где используется |
| --- | --- |
| `paper-grain.svg` | зерно бумаги: фон, шапка, карточки, подвал |
| `material-felt.svg` | направление «Контекст» |
| `material-steel.svg` | направление «Агенты» |
| `material-rubber.svg` | направление «Инструменты» |
| `material-kraft.svg` | направление «Практика» |
| `surface-desk.svg` | подложка первого экрана |
| `surface-slate.svg` | подложка атласа |

Все текстуры — SVG с `feTurbulence`, без растровых зависимостей и внешних запросов.
Они красятся через CSS-переменные и работают в обеих темах.

Чтобы заменить их на AI-текстуры, используйте готовые промпты в
`garden-gpt-image-2/prompt/tactile-materials-20261122-2138.md` и переменные
`--tex-*` в `src/styles/tactile.css`.
